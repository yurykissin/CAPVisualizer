    Compare two exports

    Compare any two CAPVisualizer snapshots to see exactly what changed in your Conditional Access configuration between them. Everything runs locally in your browser - no file is uploaded and no network call is made.

    Which files to pick. Each CAPVisualizer run writes a raw export at output/<timestamp>/raw/export.json. Pick two of these export.json files from different runs (the folder name is the run date/time). You can also use any JSON file this tool produced in that shape.

    1. Source (baseline) - click Choose File and select the older export you want to compare from.
    2. Target (compare to) - click Choose File and select the newer export you want to compare against.
    3. Click Compare. Use Swap to flip the two sides if you picked them in the wrong order.

    What you get. A summary of policies added (only in the target), removed (only in the source), and modified, plus a field-by-field Source → Target table for every changed policy. Policies are matched by their id, so renames show up as a change rather than an add/remove pair. All timestamps are shown in your local time.

    Compare two policies

    Pick any two Conditional Access policies from this export to see their configuration side by side and a field-by-field comparison. Each config panel is collapsible - open one section (Users, Target resources, Conditions, Access controls) and it opens on both sides so they line up. Everything runs locally in your browser.
